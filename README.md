# 超市购物低保真微信原生小程序

使用微信开发者工具导入当前目录 `D:\小程序\微信\超市`，选择小程序，使用测试号（配置为 touristappid）或你自己的 AppID，然后编译。入口为 `pages/shop/index`。无需安装依赖。

首页、分类、购物车、我的共用页面状态。搜索、分类、活动筛选、详情、加购、数量、勾选、删除确认、优惠券、订单提交、订单查询、门店选择与通知均可交互。

演示数据仅保留在当前会话；重新编译会重置。订单不接入支付、后台或配送；提交后以门店自提订单展示。满39减10优惠按已勾选商品金额计算。数量范围1–99。

“我的 → 原型状态预览”可触发加载、空列表及错误重试。购物车初始为空，完整成功与确认状态可通过加购、结算触发。

运行验证：`node --test tests/shop.test.js`。

布局使用双列卡片、底部固定导航和安全区间距；宽屏最大内容宽度780px。原生项目需在微信开发者工具或微信运行，不能作为网页直接打开。
